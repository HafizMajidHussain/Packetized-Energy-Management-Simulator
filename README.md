# PEM-For-Smart-Homes
## Test Plateform
- Matlab 2018b
## Datesets
The following datesets have been used
- Electricity pricing (buying and selling) information has adopted from (https://hourlypricing.comed.com/) and [Optimal stochastic
energy management of retailer based on selling price determinationunder smart grid environment in the presence of demand response program](https://www.researchgate.net/publication/310605383_Optimal_stochastic_energy_management_of_retailer_based_on_selling_price_determination_under_smart_grid_environment_in_the_presence_of_demand_response_program)
- Energy consumption/power ratings information has adopted from paper titled  [Power Consumption Pattern Analysis of Home Appliances for DC-based Green Smart Home](https://www.koreascience.or.kr/article/CFKO201035738815006.pdf)
